TOP1 SHOP UID Name Check
========================
This is a frontend UID -> player-name checker.

It uses a third-party public Free Fire API endpoint as an example. It is NOT an official Garena API and can stop working or change.

For a production website, use an API/service you are authorized to use. If it requires a secret API key, do not put that key in GitHub Pages frontend code; use a server/backend instead.
